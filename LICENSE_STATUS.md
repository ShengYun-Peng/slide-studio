# License and release status

No public software or asset license has been selected on the owner's behalf.
Repository availability does not grant additional rights to third-party assets.

Before releasing it, the owner should choose a license for their code and docs,
review the asset provenance manifest, and decide which examples to include.
System fonts are referenced by name, not bundled. Native Apple frameworks and
Keynote are requirements, not redistributed components.

Asset groups have different roles:

| Asset group | Current use and release status |
|---|---|
| Procedural patterns and neutral cinematic title | Original graphics generated by source code and system fonts; no third-party footage is needed for these examples. The owner still chooses the project's public code/content license. |
| `assets/research/` | Packaged synthetic teaching material used by the richer training demos. Provenance identifies the defense source; the table is illustrative, not clinical data. |
| `assets/device/` | Apple hardware movie and screen-registration data used by the current high-fidelity device demo. The original footage and derivative gallery composite are local-review assets; public redistribution has not been cleared. |
| `assets/cinematic/tesla-reference/` | Tesla vector logo and Cybercab footage used only by the Tesla AI variant. The derived Tesla demo is also a local reference; public redistribution has not been cleared. |
| `assets/reference/` | Optional historical footage, figure exports, and recipes retained for study. This archive is excluded from Git by default and is not a runtime dependency of the neutral examples. |

The polished device composition needs its hardware source; it is not an
asset-free procedural laptop. The neutral cinematic title remains usable without
the Tesla assets. Before publishing, inspect the actual Git file list as well as
the provenance records, and omit or replace any source and derived movie whose
rights have not been resolved. An asset's presence in the local gallery is not a
claim of redistribution rights.

Keep private source material and real participant photos out of the public
example. Use your own sources in `my-project/sources/` and record their provenance.
