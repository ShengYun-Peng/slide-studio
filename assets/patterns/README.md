# Original procedural artwork

These five animation families need no external images. Their document, table, chart, milestone path and UI handle are drawn from source in `runtime/renderers/presentation-patterns.swift` using the content in each scene JSON.

Optional `source_image`, `before_image`, and `after_image` inputs let a new project substitute its own evidence. Those files must be kept with that project and recorded in its source manifest. The renderer does not bundle a font: it uses the named macOS system font.

The included numbers and document are illustrative. No experimental results, private photographs, third-party footage, logos or proprietary assets are embedded in these demos.
