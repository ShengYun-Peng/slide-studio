# Assets

`primitives/` contains original, editable SVG components for reuse in Figma, Keynote or code. The Swift runtime draws equivalent shapes procedurally and does not need to load these files. These are useful starting points, not screenshots of flattened diagrams.

`reference/` is a selected local archive of the actual raw materials used for the defense. It includes provenance and has a separate redistribution policy. Default demos do not load it. Do not publish it without reviewing the rights of each asset.

For a new project, place user-specific photos, logos, screenshots, clips and measured datasets in `my-project/assets/` and record their origins and allowed use in the project asset manifest. Keep clean originals; transformations should produce new derivative files. Prefer a screen slot, vector component or measured dataset over a full-slide screenshot.
