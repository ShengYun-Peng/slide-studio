# Device hardware plate

This folder makes the high-fidelity device scene independent of the defense folder.

- `apple-pv-open-large-2x.mp4`: original Apple product-animation footage used for the defense opening.
- `screen-tracking.json`: source-frame display corners; the renderer also uses a smooth fitted lid path and physical rim correction.
- `provenance.json`: source URL, hashes, and release status.

This is local reference media. The original footage and derivative rendered gallery video require rights review before public redistribution. The desktop/chat screen itself is generated by the scene renderer and can be replaced through JSON content or `screen_image`.
