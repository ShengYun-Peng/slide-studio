# Cinematic reveal assets

The neutral title demo uses no external media: its mark, studio light field,
platinum face, and moving glints are generated from code and system-font paths.

`tesla-reference/` holds two small local reference assets used by the Tesla AI
variant: the red Tesla vector logo and the stable Cybercab night clip that was
used in the defense. Neither is required by the neutral renderer. Their hashes,
source information, and unreviewed redistribution status are in
`provenance.json`. Keep them separate from the public neutral example.
